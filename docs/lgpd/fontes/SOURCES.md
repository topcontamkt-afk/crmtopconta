## Âncoras

- Artigo da resolução/lei: `#art-N` (ex.: `lei-13709.md#art-7`, `lei-13709.md#art-55-j`).
- Artigo do regulamento anexo, que reinicia a numeração: `#anexo-art-N` (anexo único) ou `#anexo-i-art-N`
  (vários anexos). Ex.: prazo de comunicação de incidente em `anpd-res-15-2024-incidentes.md#anexo-art-6`.
- Guia (PDF): `#p-N` = página N do PDF.
- Texto de **outra lei** citado entre aspas (ex.: o art. 60 da LGPD alterando o Marco Civil) aparece como
  citação (`>`) e não gera âncora.

## Conferência feita

- Lei: 80 âncoras únicas (arts. 1–65, mais 55-A a 55-M e 58-A/58-B); nenhum artigo duplicado. No original,
  o art. 57 vem escrito "Art. 5 7." e foi normalizado. Os arts. 7, 18, 37 e 48 foram conferidos com o HTML.
- Res. 2/2022: o regulamento termina no art. 16 do Anexo I, igual ao original.
- Res. 15/2024: arts. 1–3 da resolução + arts. 1–24 do anexo.

## Como atualizar

1. Baixar o ato novo para `original/` (nunca editar arquivo em `original/`).
2. Gerar o Markdown com [`ferramentas/to_md.py`](ferramentas/to_md.py), que depende de `beautifulsoup4` e,
   para PDF, de `pypdf`:
   ```bash
   python -I ferramentas/to_md.py html original/X.html X.md --title "..." --source URL \
     --sha "$(sha256sum original/X.html | cut -d' ' -f1)" [--encoding cp1252] [--start REGEX]
   python -I ferramentas/to_md.py pdf original/X.pdf X.md --title "..." --source URL --sha ...
   ```
3. Atualizar a tabela acima e conferir as âncoras usadas em `.claude/skills/lgpd-audit/references/`.
